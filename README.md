# FATALSTROKE

Bağımsız oyun stüdyosu **FATALSTROKE**'un resmi tanıtım sitesi.

🌐 **Canlı:** [www.fatalstroke.com](https://www.fatalstroke.com)

## Oyunlar

- **Neon Drift** — Neon dolu arcade sürüş
- **Voidbreaker** — Uzay temalı aksiyon
- **Pixel Siege** — Pixel art kuşatma
- **Echo Protocol** — Sci-fi gerilim
- **Ironclad Arena** — Roguelike arena dövüşü

## Özellikler

- Karanlık, neon temalı modern arayüz (mor / cyan vurgu)
- Tamamen responsive tasarım
- SVG inline favicon, hızlı yüklenme
- Google Fonts (Orbitron + Inter) ile özel tipografi
- Animasyonlu arka plan (grid, orb, noise katmanları)
- SEO + Open Graph + Twitter Card meta etiketleri

## Teknolojiler

Vanilla web stack — framework yok, build adımı yok:

- HTML5
- CSS3 (custom properties, grid, flex, animations)
- JavaScript (ES modules, vanilla)
